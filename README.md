# Object Tracking

A real-time object tracking project demonstrating the fundamentals of computer vision.

## What This Is

A portfolio project showing the complete pipeline of **object detection + tracking**. It detects objects in a video stream and follows them across frames with unique IDs.

## Features

- **Real-time detection** using YOLOv8 (80+ object classes)
- **Object tracking** with IoU-based matching
- **Class labels** showing what each object is (person, car, cup, etc.)
- **Color-coded boxes** by object type
- **Flag system** for vehicles (red boxes with "!! FLAG !!")
- **FPS counter** for performance monitoring
- **Unique IDs** that persist across frames
